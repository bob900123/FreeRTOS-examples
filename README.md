
# FreeRTOS Examples

STM32 FreeRTOS 練習與實作範例，使用 STM32F103C8T6、STM32CubeMX、CMake 與 VSCode 開發，涵蓋任務管理、排程、任務同步及任務間通訊等 RTOS 基礎功能

## 範例列表

| 編號 | 專案 | 說明 |
|------|------|------|
| 01 | Task Create | 建立與刪除任務，實現 LED 閃爍及按鍵控制任務 |
| 02 | Task Suspend | 暫停與恢復任務，實現 LED 閃爍及按鍵控制任務 |
| 03 | Delay Time | 比較相對時間延遲與固定週期延遲的差異 |
| 04 | Queue | 使用  Queue 實現任務之間的通訊 |
| 05 | Binary Semaphore | 使用 Binary Semaphore 實現任務之間的同步 |
